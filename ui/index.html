Traffic capture

Capture reads packets to and from this computer, plus broadcast traffic every device on the LAN receives (ARP, DHCP). That powers traffic stats, the DNS log, and the spoofing, rogue-DHCP, port-scan and malware-lookup detectors. Other devices' private traffic isn't visible from a laptop on a switched or Wi-Fi network — to watch the whole network, run NetWatch on a machine connected to a mirrored switch port.

Location

NetWatch uses your location only to show nearby Wi-Fi network names and to warn you if an unknown tracker travels with you. It never leaves this Mac: it is kept in memory, never saved or sent anywhere, and never recorded alongside other people's Wi-Fi networks or Bluetooth devices.

Use Location Services
Turning it on makes macOS ask for permission. Wi-Fi names and BSSIDs appear in the Wi-Fi analyzer, the Connection page and the look-alike Wi-Fi check. The tracker warning also needs the nearby Bluetooth scan: if an unknown tracker is near this Mac before and after it moved 1 km or more over 15 minutes or more, that's a High alert.

Security audits

Checks of your own network and this computer, with results on the Security → Audit page. Each one takes a baseline the first time it looks and alerts on changes after that.

Weekly port audit
Once a week, checks the common ports on every online device and alerts when one newly opens.
New listening apps
Alerts when an app on this computer starts accepting connections from the network.
Startup items
Alerts when a launch agent or daemon is added (macOS). Serious if it runs from a temporary or hidden folder or isn't properly signed.
DNS and router changes
Alerts when this network's DNS servers change to ones it never used, or its DHCP server changes.
Look-alike Wi-Fi
Watches for another access point using your network's name with weaker security. Needs Wi-Fi names to be visible.
Certificates and HTTPS
Checks the HTTPS certificates of watched sites every 6 hours, and once a day whether something is intercepting HTTPS.

Expert mode & log export

For people who want the technical picture, or who collect logs elsewhere. New alerts can be written to a file and sent to a SIEM or log collector; nothing leaves this computer unless you enter an address below.

Expert mode
Each alert gets an "Expert details" section: the MITRE ATT&CK technique and tactic, why it matters, what to do, and the raw alert as JSON.
Log file
Appends each new alert as one JSON line to alerts.jsonl in the data folder, starting a new file at 10 MB (the old one becomes alerts.1.jsonl).
Each new alert goes to this address as a syslog message (RFC 5424) over UDP, for example siem.lan:514. Leave it empty to switch this off. Only that address is ever contacted.

Data allowance

If your internet plan has a monthly data cap (common on 4G and 5G), NetWatch alerts at 80% and 100% of it, using your router's counters. It also forecasts where the month is heading and warns once if you're on course to go over.

Threat intelligence

Sources: abuse.ch URLhaus (malware domains), abuse.ch Feodo Tracker (botnet servers), abuse.ch ThreatFox (malware domains and botnet command-and-control servers), and the Wireshark manufacturer database (device vendors).
